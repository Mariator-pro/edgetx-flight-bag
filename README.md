# edgetx-flight-bag

Flight Bag (EdgeTX UI): one settings tool for [Lipo Nanny](https://github.com/Mariator-pro/edgetx-lipo-nanny), [ELRS Link Sentinel](https://github.com/Mariator-pro/elrs-link-sentinel), [GPS Homer](https://github.com/Mariator-pro/edgetx-gps-homer) and [Flight Wingman](https://github.com/Mariator-pro/edgetx-flight-wingman), built from EdgeTX's own controls (the same look as the radio menus).

[![License: GPL v2](https://img.shields.io/badge/License-GPL_v2-blue.svg)](LICENSE)
[![EdgeTX](https://img.shields.io/badge/EdgeTX-%E2%89%A5%202.12.5-brightgreen)](https://edgetx.org)

Work in progress, not released yet. Needs EdgeTX 2.12.5 or later on a colour radio.

## Files on the SD card

```
/SCRIPTS/TOOLS/FLIGHTBAGX.lua     the tool (Tools menu: Flight Bag (EdgeTX UI))
/SCRIPTS/FLIGHTBAG/LVGL/          its pages
/SCRIPTS/FLIGHTBAG/apps.lua       shared with the drawn Flight Bag
/SCRIPTS/FLIGHTBAG/*_model.lua    shared with the drawn Flight Bag
```
